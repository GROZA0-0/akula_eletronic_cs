Akula is a desktop cashier and retail management application designed for electronics stores selling phones, tablets, TVs & monitors, PC components, gaming accessories, and consoles. It combines a fast point-of-sale checkout flow with full back-office tools — inventory, staff, returns, and reporting — so a store owner can run day-to-day operations and track performance without juggling separate tools.

The system is built to scale beyond a single storefront, supporting multiple branches and warehouses under one unified account, with role-based staff access and centralized reporting.

Key Features
🧾 Point of Sale (Checkout)
Category-based product browsing (Phones, Tablets, TVs & Monitors, Accessories, PS5, PC Components)
Live shopping cart with real-time order totals
Automatic tax calculation
Order confirmation and receipt generation
Product search
📊 Dashboard & Analytics
Real-time revenue and order tracking
Sales breakdown by category (interactive chart)
Automated promotional/campaign performance reporting
Quick-access shortcuts to core modules
📦 Inventory & Product Management
Create, edit, and categorize products
Barcode assignment per item
Product image uploads
Category management
🔄 Returns & Refunds
Look up any order by ID
Line-item return processing with quantity control
Automatic refund calculation
👥 Staff Management
Full staff directory with photos and contact details
Role-based accounts (Manager, Supervisor, HR, IT, Cashier, QA, etc.)
Live employee status tracking (Active / Break / Busy / Offline)
Add new employees via a guided sign-up flow
🏢 Multi-Branch & Warehouse Support
Centralized management across multiple store branches
Per-branch and consolidated (all-branch) reporting
Warehouse-level stock tracking
